# Mittireddi Teja — Modern Frontend Developer Portfolio

A modern, high-performance personal portfolio website built with pure semantic **HTML5**, **Vanilla CSS3** (Custom Properties, Glassmorphism & Bento Layouts), and **Modern JavaScript (ES6+)**.

---

## ✨ Features & Architecture

- **Dark & Light Mode Engine:** Deep space obsidian dark mode with glowing accents, with a high-contrast clean light mode and automatic `localStorage` persistence.
- **Interactive Constellation Canvas:** Lightweight particle background that connects nearby nodes and reacts to mouse movement (automatically throttled when tab is inactive).
- **Hero Bento & 3D Interactive Card:** Interactive perspective tilt card showcasing real-time code snippet, floating status badges, and 3D avatar frame.
- **Dynamic Typewriter:** Fluid multi-title typewriter animation highlighting technical competencies.
- **Live IST Clock & Location Status:** Real-time Indian Standard Time clock (UTC+5:30) with active remote collaboration badge.
- **Animated Metrics & Stats Bar:** Number counting triggers via IntersectionObserver for instant credibility.
- **Categorized Skills Matrix:** Interactive category filtering across Frontend, Styling & Design, AI Tools, and DevOps.
- **Featured Projects Showcase:**
  - **Payzo:** Cashback platform with light/dark theme, interactive pricing and benefits tour.
  - **Freelance Web Studio:** Modern agency portfolio with service tiers and pricing packages.
  - **Samhitha Degree College:** Educational portal with course exploration and admissions intake.
- **Deep Dive Project Modals & Resume Preview:** In-page modal dialogues for detailed case studies and printable resume view.
- **1-Click Copy-to-Clipboard:** Quick copy for email and phone with instant toast feedback.
- **Validated Contact Form:** Client-side validation with character counter and direct email client dispatcher.
- **100% Responsive & SEO Optimized:** Tested across mobile, tablet, and ultra-wide viewports.

## 🚀 Running Locally

Simply open `index.html` in any modern web browser:
- Double click `index.html` in your file explorer, or
- Right click `index.html` &rarr; "Open With" &rarr; Chrome / Edge / Brave / Firefox.

## 🌐 Deployment

This project requires zero build steps and is ready to deploy directly on:
- **Netlify:** Drag and drop the `portfolio` folder to Netlify Drop, or connect via GitHub.
- **Vercel:** Run `vercel` or link repository.
- **GitHub Pages:** Go to Repository Settings &rarr; Pages &rarr; Set source to branch `main` and folder `/ (root)`.

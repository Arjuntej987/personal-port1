# Mittireddi Teja - Portfolio

Personal portfolio website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` - page structure and content
- `style.css` - all styling (colors are at the top, light/dark mode, responsive rules)
- `script.js` - typing effect, theme toggle, mobile menu, scroll animation, contact form

## Run locally
Open `index.html` in your browser.

## Deploy
Netlify / Vercel / GitHub Pages (Settings > Pages > branch `main`, folder `/root`).
